# Cisco Orbital

This repository contains practical Cisco Orbital resources for endpoint investigation, threat hunting, incident response, and forensic collection.

Cisco Orbital provides SQL-like endpoint querying powered by osquery and scripting engine power by Python, allowing security teams to inspect live endpoint state, identify suspicious activity, validate configurations, and collect key investigative data. This repository expands on that capability with reusable queries, Python scripts, and workflows designed for real-world security operations.

## Repository Focus

The content in this repository is organized around common security and DFIR use cases, including:

- Endpoint visibility and live-response investigation
- Threat hunting using Orbital and osquery-style queries
- Cisco Secure Endpoint operational validation
- Cisco XDR Forensics and memory-analysis workflows
- Volatility-assisted process, memory, and artifact analysis
- Registry, browser, file-system, and process artifact collection
- Linux endpoint isolation and containment examples
- Security posture checks across Windows, macOS, and Linux

## Audience

This repository is intended for SOC analysts, incident responders, threat hunters, forensic investigators, and Cisco Secure Endpoint administrators who want practical examples for using Cisco Orbital beyond basic catalog queries.

## Disclaimer

These queries and scripts are provided as examples. Review and test all content in a controlled environment before using it in production. Some queries or scripts may require modification based on operating system, connector version, permissions, policy configuration, or organizational requirements.
